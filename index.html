Shark Tank India: pitch explorer

About this page

A single-page explorer for all 759 pitches from Seasons 1–5. Everything is in one file. The data is built into it, so there is no build step and no server.

The Pitches tab

Every pitch with its serial number, season, episode, company, brand, founders, founder LinkedIn, website, category, deal outcome and pitch page. Use the season buttons at the top, the search box and the Filters panel (category and deal outcome). Click a column heading to sort, and click a row to see all of its details.

The Analytics tab

Headline numbers, pitches and deals by season, deal rate by category, pitches by category and season (with the % share per season), and total pitches and deals closed by category. Everything follows the season buttons, the search box and the filters.

Good to know

The source files have no valuation, ask or investor columns, so the analytics cover counts and deal rates only.

The “Other” category is the label used in the source files. It is not defined anywhere in the data.

Where the data comes from

The data is one row per pitch, with a serial number added. It is built into this page and is also kept as a data sheet (pitches.csv) in the same GitHub repository.

Pitches
759 pitches from Seasons 1–5
Pitch page
The “Pitch page” link on each row points to the page the row came from (757 of the 759 are on sharktankindia.com).

What each column means

sr_no
Serial number added to the data
season, episode
When the pitch was shown
company_name, brand_name
The company and its brand
founders
Founder names, separated by “; ”
founder_linkedin
One LinkedIn link per founder, separated by “; ” and lined up with the founders by position
website
The company website
category
The category label used in the source files
deal_secured
Yes if a deal was secured, No if not
source_url
The page the row came from

“LinkedIn profile not found” and “Website not found” mean the source had nothing for that field.

Updating the data later

The repository has a prompt file (NEXT_PROMPT.md) to paste into Claude when you want to add new information, such as valuations or sharks, and rebuild the page.
